# Kolam Connect (prototype v1)

React + Vite single-page site. No backend, no database.

## Run
    npm install
    npm run dev       # local dev server
    npm run build     # outputs dist/ for Netlify / Vercel (drag-drop dist/, or build command `npm run build`, publish dir `dist`)

## Before showing it publicly — edit `src/data/siteConfig.js`
- `whatsappNumber`: digits only with country code (e.g. `91XXXXXXXXXX`). Use a number you are authorised to publish.
- `phoneDisplay`, `locationLabel`.
Until the number is set, WhatsApp buttons open WhatsApp's "choose a contact" screen and the Phone card says "coming soon".

## Edit gallery: `src/data/artists.js` (currently SAMPLE data, not real artists)
## Artwork: original SVGs generated by `npm run art` (scripts/generate-kolam.mjs)

## Structure
src/components: Navbar, Hero, Gallery, ArtistCard, About, Contact, Footer, Icons
src/data: siteConfig.js (contact + link builders), artists.js (gallery)
src/index.css: all styles, colours in :root variables
